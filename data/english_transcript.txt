1. Hello everyone, it's Vincent and I am a data engineer and today,
2. To make it very simple, a data engineer is a professional specialized in the management and engineering of data.
3. It's one of the most sought-after jobs in the tech world.
4. Arrived at work between 9 am and 9:30 am, I have a coffee with my colleagues and we discuss a bit before holding the morning meeting with our teams.
5. After the meeting, I turn on the computer and start checking important emails.
6. I respond to the received emails and plan my day according to the order of priorities and the different projects I have to intervene in.
7. The work of a data engineer is to facilitate the work of data scientists and analysts.
8. I make sure to offer normalized data, that is to say data in a uniform format.
9. Example: men are 0, women are 1.
10. We don't have male/female, M/F, etc.
11. I also check that the data is complete, that there are no missing values, but also that the data is consistent by creating clean and well-organized tables so that data analysts and scientists can focus only on their task.
12. I then get to work on a data pipeline creation project.
13. For those who don't know what it is, a data pipeline is the process of extracting, transforming, and recording data in a format suitable for its use.
14. I will therefore extract data by doing web scraping, by searching for information in the HTML code of web pages, by making API queries, HTTP requests to receive information.
15. Once the data is extracted, I transform it to put it in a table or data frame, I then do data cleaning, for example by removing duplicates, by changing women to 1, by deleting all useless data to clarify the data frame as much as possible.
16. Once the data frame is ready, I record the data in a database in a table or without structure.
17. I finish by creating a database schema and a data flow plan.
18. I usually have a meal around 12:30 pm, but it depends on my progress on the morning's work as well as the availability of my colleagues.
19. After the lunch break, I return to work and I make sure that all the data is processed correctly and that the information is stored in the database.
20. Data processing makes it possible to offer clean and transformed data according to uses.
21. For example, we only want numbers to define prediction models, for this step, I will use specialized libraries like Pandas, Spark, etc.
22. and I use languages that can perform actions on a large volume of data in record time, in order to optimize my time at work.
23. As for storage, we can store data in the cloud or on a local server, or even on one's computer.
24. Depending on the needs, I can transform the data into an SQL table or JSON documents for MongoDB.
25. I feed my database using a database management system also called DBMS.
26. Once I have taken care of data storage, I move on to optimizing the performance of the data pipeline by examining the critical points and making adjustments, such as working on the quality of my code to ensure good documentation and better readability.
27. I like to finish my day by doing watch, it's useful to me when the techniques I use become obsolete.
28. In general, I like to discuss it with my colleagues.
29. It's always interesting to learn from others about new tools and new technologies.
30. Just like today, I'm going to train on AWS cloud to get certified.
31. I usually leave the office around 6 pm, once my daily schedule is finished.
